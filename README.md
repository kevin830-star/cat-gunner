# 猫咪保卫战

一款原创的 2D 俯视角射击小游戏：扮演一只小猫，拿枪赶走入侵者，保卫猫窝，同时学习中文。

## 怎么玩

直接用浏览器打开 `index.html`，不需要安装或构建。

- 电脑：WASD 移动，鼠标瞄准并按住射击，Q/E 或数字键换枪，空格使用猫薄荷，P 暂停。
- 手机：在屏幕上拖动来移动，自动瞄准射击。

每关 60 秒，过关后进入商店，可以购买武器、合成更高品级的武器、补充道具，强化猫咪和猫窝。

### 武器品级与合成

- 武器分 D → C → B → A → S → SSS 六个品级，品级越高伤害越大、射速越快，颜色和命中特效也越华丽。
- 在商店购买的都是 D 级。相同品级的武器凑够数量就能合成一把更高一阶的：D、C、B 需要 2 把，A、S 需要 3 把。有「一键合成」按钮。
- 每种武器都有各自的命中效果和命中范围：豌豆手枪 C 级起有溅射，毛线散弹枪每升一阶多一颗弹丸，鱼骨冲锋枪 A 级起有溅射，榴弹炮爆炸范围随品级变大，激光光束随品级变粗。溅射和爆炸的范围会在地上画出圈。

### 道具有使用次数

道具不是买一次永远有效：买一包得到若干次使用次数（最多存 9 次）。除了猫薄荷（手动使用，每用一次消耗 1 次），其他道具每关开始时自动消耗 1 次，次数用完就失效，需要再买。「升级」提高的是道具强度，会一直保留。

### 星级

每关结算时按猫咪和猫窝各损失了多少生命来评星：两者平均损失 ≤15% 得 3 星，≤40% 得 2 星，否则 1 星。2 星和 3 星有额外的小鱼干奖励。

进度会自动保存在浏览器里：每次过关进入商店时，以及在商店里的每次操作后。下次打开时在主菜单点「继续游戏」，会回到上次的商店。关卡打到一半退出的话，这一关要重打；猫窝被攻破或猫咪倒下后，存档会清除。

## 战斗中的特别内容

- **九种头目**：每 3 关一个，其中每第 5 个头目（第 15、30 关……）是巨龙，其余按顺序轮流出场。头目血量比普通关卡高，各有带动作的招式，出招前地面会出现红色预警。巨龙会喷火扫射，还会召唤陨石雨。
  野狗（叫来老鼠）、狐狸（突然冲刺）、大灰狼（嚎叫让敌人加速）、大象（跺脚震地）、长颈鹿（吐一排树叶弹）、老虎（跳起扑人）、狮子（吼声震飞猫咪）、犀牛（直线冲撞）。
  野狗（叫来老鼠）、狐狸（突然冲刺）、大灰狼（嚎叫让敌人加速）、大象（跺脚震地）、长颈鹿（吐一排树叶弹）、老虎（跳起扑人）、狮子（吼声震飞猫咪）、犀牛（直线冲撞）。
- **小头目**：第 2 关起，每关中途会出现戴铁桶的鼠队长，血厚、会冲刺。打败它必定掉落一个增益和一堆小鱼干。
- **增益与变身**：敌人被打败时有小概率掉落写着汉字的增益球。捡到后猫咪会变身（变大、变色）：大（变成巨猫踩扁敌人）、力（攻击加倍）、快（射击变快）、盾（暂时无敌）、冰（冻住敌人）；另有 心（恢复生命）、吸（吸来所有小鱼干）。捡到时会显示词语和拼音并朗读。
- **酷道具**：旋转飞镖（绕猫窝旋转切敌人）、闪电云（定时劈敌人）、小猫助手（跟着你开枪），都按使用次数消耗。
- **过关动画**：时间到后入侵者逃跑，猫咪欢呼，放烟花。点击屏幕可以跳过。

## 中文学习

- **头目战填空**：每 3 关有一个头目。头目登场和血量降到一半时各出一道词语填空题，答对一题本关攻击力 +50%。
- **汉字小游戏**：每次进商店可以玩一次（看图选字、偏旁拼字、选声调轮换），答对获得小鱼干。
- 答题后显示拼音和英文释义，并朗读（需要浏览器支持中文语音）。拼音可在菜单中关闭。

## 文件

- `index.html` / `style.css`：页面和界面样式
- `data.js`：武器、道具、敌人数值和中文题库（想加题目改这里）
- `bosses.js`：八种头目的数据和画法
- `sound.js`：音效合成（不使用音频文件）
- `icons.js`：武器、道具图标（代码绘制，商店和猫咪手里的枪共用）
- `game.js`：游戏逻辑和绘图
