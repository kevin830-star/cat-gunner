# 猫咪保卫战 (Cat Gunner)

一款结合 2D 俯视角射击与分级中文学习的轻量级网页游戏——扮演拿枪的小猫咪赶走入侵者、保卫猫窝，在战斗和闯关中学习汉字偏旁、词语、成语、古诗与拼音读音。

## 怎么玩
- 直接在浏览器打开 `index.html` 即可游玩，无需安装依赖或构建打包。
- **电脑操作**：`WASD` 或方向键移动 · 鼠标瞄准并按住左键射击 · `Q`/`E` 或数字键 `1-5` 换枪 · `F` 释放冲击波 · `空格` 使用猫薄荷 · `P` 暂停；答题时可用数字键 `1-4` 快速选择、`空格/回车` 继续。
- **手机/平板操作**：左侧屏幕拖动移动 · 自动瞄准最近敌人射击 · 点击右下角圆形按钮切换武器或使用手动道具。
- **每关自动回满血**：每个关卡开始时，猫咪的生命值自动恢复至上限。

   - 若关卡中途猫咪倒下或猫窝被攻破，每关可参加一次 **中文复活考试**（共 **10 题**：3 道偏旁填空 + 3 道词语填空 + 2 道成语填空 + 2 道读音选择）。
   - **答对 8 题或以上** 即可当场满血复活、修复猫窝、获得短暂无敌护盾并震退周围敌人继续战斗！
4. **关底双倍血量头目 & 5 秒慢镜头金光觉醒特写**：
   - 头目在头目关的最后阶段（倒计时最后 3 秒）压轴登场，并且 **血量翻倍**。
   - 答对头目战的中文题后，除本关攻击力 `+50%` 外，还会触发 **5 秒慢镜头镜头拉近特写**——猫咪全身变大变红，周身金光持续上升！
5. **击败头目逐步解锁道具与解锁动画**：
   - 游戏开始时道具里只有 **猫薄荷**，其他道具都还锁着。
   - **每打败一个头目按顺序解锁一种新道具**：自动炮塔 → 冲击波 → 铁丝围栏 → 磁铁项圈 → 旋转飞镖 → 闪电云 → 小猫助手，并播放全屏光芒旋转的 **新道具解锁动画**。

   - 使用后释放全屏强力冲击波，清除敌方弹幕，所有敌人被震晕并向后 **震退五格（500 像素距离）**。

## 汉字小游戏与语音提示
- 每关结束后会自动弹出汉字小游戏，共 6 题，每答对一题得小鱼干，全对再额外 +30。
- 小游戏有六种题型：看图选字、偏旁拼字、词语填空、成语填空、读音选择（声调或多音字）、古诗填空。每关 6 题，每种题型各一题，顺序随机。
- 屏幕上出现中文提示时（新敌人、小头目、敌人潮、头目登场、道具解锁、觉醒、复活等）会同时用中文语音念出来；关闭声音后不念。

## 道具、升级与防御（本次更新）
- **道具永久拥有、不限次数**：买一次就一直有，被动道具每关自动生效；猫薄荷、冲击波用完后冷却一会儿可以再用。炮塔、飞镖最多同时 4 个。
- **道具合成升级**：已拥有的道具可以「合成升级」（相当于再买一份合进去），最高 5 级，等级越高威力越大，并播放合成动画。
- **猫咪护甲、加固猫窝不限等级**：前 10 级每级换新造型——猫窝：纸箱小窝 → 加固小窝 → 大猫窝 → 花窗大猫窝 → 猫别墅 → 阳台猫别墅 → 花园猫别墅 → 猫城堡 → 旗帜猫城堡 → 高塔猫城堡 → 黄金猫城堡；猫咪：红围巾 → 小斗篷 → 帽子 → 铁头盔 → 羽毛头盔 → 骑士铠甲 → 金头盔 → 黄金铠甲 → 王冠 → 猫咪国王。10 级以后只换颜色。
- **猫窝护盾**：地上新增掉落「护」字增益，捡到后猫窝 10 秒内不受伤害。
- **导弹防御**：猫窝升到 3 级后，每关可以用一次（R 键或右下角导弹按钮），从猫窝向四面八方发射导弹，碰到第一个敌人就爆炸造成范围伤害；猫窝等级越高，导弹越多越强。
- **复活考试不限次数**：每次猫或猫窝生命归零，都会提示「进行中文测验，答对 8 题即可复活」，点「开始」按钮开始答题。
