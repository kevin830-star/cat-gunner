# 学习游戏乐园

边玩边学中文和数学的网页小游戏合集，手机、平板、电脑都能玩，不用安装。

在线玩：https://kevin830-star.github.io/cat-gunner/

打开后是 **游戏大厅**：用动态卡片展示可以玩的游戏，点一下卡片就进入游戏；每个游戏里都有「返回游戏大厅」按钮。每个游戏的进度都会自动保存在这台设备上。

## 🐾 宠物学院大乱斗（第 2 版）

你是魔法学院的新生，收集魔法宠物，组成最多 3 只的小队，挑战新手草原的 6 位对手和草原擂台主。

- **答题出招**：每个技能都带一个科目（📖 中文 / 🔢 数学），选技能就要答一道题。
  - 答对：正常伤害；在倒计时的「暴击区」内答对：**暴击 ×1.5**；答错：威力减半，并显示正确答案和讲解（点「知道了」继续）。
  - 「难题」技能威力更大，题目也难一级。
  - 连续答对 3 题攒满 **必杀能量**，可以放全屏必杀技。
  - 对手出招时有时会出 **防御题**：答对伤害减半，答得快直接闪避。
- **属性克制**：🔥 火 → 🌿 草 → ⚡ 雷 → 💧 水 → 🔥 火；✨ 光、🌑 暗互相克制（克制 ×1.5，被克 ×0.7）。
- **队伍搭配**：同时带上擅长中文和擅长数学的宠物，全队攻击 +10%。
- **12 只原创宠物**：火尾喵、泡泡獭、叶叶兔（三选一做初始宠物）、电丸鼠、星星鹿、影子猫（在冒险中加入）；小火狐、圆圆鲸、蘑菇龟、静电羊、小天马、小蝙蝠（从宠物蛋里孵出来）。每只有 4 个技能和 1 个必杀技，「我的宠物」里有图鉴。
- **稀有度**：N / R / SR / SSR，稀有度越高基础属性越好。
- **🥚 孵蛋屋**：普通蛋 100 金币（N 60% · R 30% · SR 9% · SSR 1%），稀有蛋 300 金币（R 50% · SR 38% · SSR 12%）；答对 3 题把宠物从蛋里唤醒，有破壳光芒动画。第 3 关、第 6 关送普通蛋，草原擂台主送稀有蛋。
- **⭐ 升星**：用 2 只相同的宠物给它升 1 星（最高 5 星），每星属性 +10%。出战中的宠物不会被用掉。
- **✨ 进化**：10 级可以进化成第二形态（披上元素披风），20 级进化成终极形态（戴上皇冠、有光环）；进化前要通过「进化考验」（3 题答对 2 题）。进化后属性大幅提升，必杀技威力 +10。对手到了 10 级、20 级也会以进化形态出场。
- **⚒️ 装备工坊**：力量项圈（攻击）、守护披风（防御）、元气铃铛（生命），每只宠物各穿一件；两件相同等级的装备合成高一级（Lv.1 +6% … Lv.5 +33%）。打赢比赛有机会掉落装备。
- **成长**：打赢比赛、答对题都给经验和金币，宠物升级变强；道具商店卖回血药水、护盾泡泡、力量糖、复活羽毛、经验糖果。
- **星级**：每关按正确率评星（90% 以上 3 星，70% 以上 2 星）。
- **多个玩家**：每个孩子建一个自己的玩家，名字、头像、中文年级和数学年级可以分开设置（一到六年级），存档互不影响。
- **设置**：答题时间（宽松 30 秒 / 标准 20 秒 / 挑战 12 秒）、拼音、语音读题、音效。
- 题目由语音朗读（中文），可以按 🔊 再听一遍；电脑上可以用数字键 1-4 选答案。

### 题库

- **中文**：`shared/zh-bank.js`（与猫咪保卫战的题库相同）（看图选字、偏旁拼字、词语填空、成语填空、古诗填空、读音选择），按年级分级。
- **数学**：`pets/math.js` 按年级随机出题——一年级 20 以内加减；二年级两位数加减、乘法口诀、表内除法；三年级三位数加减、乘除、有余数的除法、周长；四年级两位数乘法、混合运算、简便运算、面积；五年级小数、解方程、分数、三角形面积；六年级分数运算、百分数、圆的面积、比例。每题都有讲解。
